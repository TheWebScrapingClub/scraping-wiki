# Nimble x Web Scraping Club Challenge

> Summary of an article published on [The Web Scraping Club](https://www.scraping.club/?utm_source=wiki&utm_medium=referral&utm_campaign=article_summary) on 2023-06-22 (free to read). **[Read the full article](https://www.scraping.club/p/nimble-x-web-scraping-club-challenge?utm_source=wiki&utm_medium=referral&utm_campaign=article_summary)**

Nimble and I are running a web scraping challenge for The Web Scraping Club community. Nimble designed the task. The goal is to solve a data collection problem inside a fixed time window with real tooling, not a toy example. It is open to experienced analysts, aspiring data scientists and anyone curious about data collection.

Every participant gets access to Nimble's data collection APIs for up to 72 hours, and those APIs are what you use to solve the task. The challenge starts on Tuesday, June 27 and runs non-stop for those 72 hours. You enter through a sign-up form. The top performers get rewarded. It is also a hands-on way to see how Nimble's data platform behaves on a real job, if you have not worked with it yet.

## What's inside

- The top 10 performers each receive $1,000 in credits on Nimble's platform and a month of free Web Scraping Club content.
- The first-place winner also gets a $500 Amazon gift card.
- The announcement does not describe the task itself, only the format, the timing and the tools available.
- The profile we have in mind is broad: data analysts, budding data scientists and tech enthusiasts interested in AI.
