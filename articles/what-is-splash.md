# What is Splash?

> Summary of an article published on [The Web Scraping Club](https://www.scraping.club/?utm_source=wiki&utm_medium=referral&utm_campaign=article_summary) on 2023-02-06 (free to read). **[Read the full article](https://www.scraping.club/p/what-is-splash?utm_source=wiki&utm_medium=referral&utm_campaign=article_summary)**

Most headless browsers were built for testing, not for scraping. Splash is one of the few designed for data extraction from the start, and that matters when the target renders content with JavaScript and a plain HTTP request returns an empty shell.

In this short piece I introduce Splash and what sets it apart from other headless browsers: a Lua scriptable interface, a fast JavaScript rendering engine and an HTTP API. I then go through the jobs it is used for. These are extracting text, images and other content from websites, automating tasks such as filling out forms and clicking links, and scraping dynamic sites that depend on JavaScript. It is an overview for people who have not used the tool yet and want to know what it does before deciding whether to try it.
