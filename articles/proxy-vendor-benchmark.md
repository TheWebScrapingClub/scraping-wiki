# The Great Proxy Vendors Benchmark

> Summary of an article published on [The Web Scraping Club](https://www.scraping.club/?utm_source=wiki&utm_medium=referral&utm_campaign=article_summary) on 2022-10-13 (free to read). **[Read the full article](https://www.scraping.club/p/proxy-vendor-benchmark?utm_source=wiki&utm_medium=referral&utm_campaign=article_summary)**

New proxy vendors show up every day. Tracking every offer and being sure you spend the right budget is getting hard, especially when each vendor packages and prices its plans differently.

We built a spreadsheet called The Great Proxy Vendors Benchmark and made it public, so anyone can read the data we gathered. It compares vendors on the size and the price per GB of the four types of proxies typically available. It also compares what each vendor charges for the smallest amount of GB you can buy, which matters if you want to test a provider before committing. It is a price and size comparison for now. It does not yet rate IP quality, compare cost per IP instead of per GB, or measure subnet diversity. If you spot a mistake or want to suggest something, you can write to me directly.

## What's inside

- The benchmark covers the four proxy types typically sold, each compared on size and price per GB.
- It lists the cost of the smallest GB package each vendor sells, useful for low-budget tests.
- Known gaps: no IP quality evaluation, no cost per IP, no subnet diversity check.
- Corrections and suggestions are welcome by email, so the data can be improved over time.
