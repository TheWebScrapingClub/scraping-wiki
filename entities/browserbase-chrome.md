# Browserbase Chrome

## What it is

Browserbase Chrome is utilized for running real-browser Quality Assurance (QA) against deployed previews of projects.

## How it works

Every Pull Request (PR) runs against the preview deploy using Browserbase Chrome. This process incorporates residential proxies, real DOM rendering, and captures screenshots and video attachments for review.
