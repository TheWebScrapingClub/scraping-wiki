# Lightpanda

## What it is

Lightpanda is a browser built for AI and automation, offering faster execution and lower memory usage compared to Chrome. It is designed to be more efficient and secure for AI workloads, with features such as instant startup and support for headless operation.

## How it works

Lightpanda is built from scratch using the Zig programming language, which is designed for performance and efficiency. It is purpose-built for headless operation, without rendering overhead. The browser is optimized for speed and memory usage, with benchmarks showing it to be 11x faster and using 9x less memory than Chrome. It is designed to handle resource-intensive web scraping and empower AI agents with web capabilities.
