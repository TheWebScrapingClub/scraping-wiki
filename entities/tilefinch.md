# Tilefinch

## What it is

Tilefinch is a project focused on improving page rendering, handling large scripts, and enhancing the overall browsing experience on complex websites.

## How it works

The project aims to improve page rendering by admitting large scripts and styles within measured memory bounds. This approach is designed to reduce pauses and repeated work on JavaScript-heavy pages.

It also focuses on improving page display and Treadline, offering better Basic view recovery and refining the Treadline Arena.
