# Konform Browser

## What it is

Konform Browser is a stealth browser based on Firefox ESR, designed for web scraping and automation.

## How it works

Konform Browser is built on top of Firefox ESR and supports importing profiles from various browsers, including Firefox, Firefox ESR, Floorp, IronFox, LibreWolf, Midori, Palemoon, Waterfox, and Zen Browser. It includes features such as support for importing Bookmarks, Browser History, Passwords, Form Data, and Cookies. Additionally, it updates privacy settings, including First-Party Isolation.
