# ticket.js

## What it is

`ticket.js` was an anti-bot system used by Supreme during their Spring 2021 season. It generated a `ntbcc` cookie by performing various browser challenges to create a unique browser fingerprint. This fingerprint was then encrypted and embedded within the cookie, which Supreme's servers would decrypt to verify the authenticity of the request.

## How it works

The `ticket.js` system aimed to prevent botting by requiring a valid `ntbcc` cookie, which was generated by executing a series of browser challenges. These challenges included checks for webdriver, canvas fingerprinting, and media playback capabilities, all designed to create a browser fingerprint. This fingerprint, along with a decrypted token obtained from a `/live.json` request, was then encrypted using a specific key to form the final `ntbcc` cookie.

To bypass this system, one would need to obtain the decryption key for the `/live.json` token, the browser-specific fingerprint, and the final cookie encryption key. With these components, it was possible to decrypt the `/live.json` token, concatenate it with the known fingerprint, and then encrypt this combined data using the cookie encryption key to arbitrarily generate valid `ntbcc` cookies.
