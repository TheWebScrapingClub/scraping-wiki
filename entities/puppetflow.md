# Puppetflow

## What it is

Puppetflow is a self-hosted browser automation platform designed for building, running, scheduling, and monitoring JavaScript workflows. It is powered by Puppeteer and allows users to manage complex browser automation tasks within a controlled, self-hosted environment.

## How it works

The platform enables users to build browser workflows using JavaScript. Workflows can be executed manually, on a schedule, or through integrations. Users can watch browser sessions live and take control when necessary, providing a human-in-the-loop capability for automation.

Features include organizing flows and reusable snippets in workspaces, managing variables and secrets, and deploying the solution on custom infrastructure using Docker.
