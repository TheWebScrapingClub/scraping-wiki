# ScrapingSandbox

## What it is

ScrapingSandbox is a web scraping sandbox for learning and testing web scraping techniques. It provides 500+ sample products from open-source e-commerce datasets, allowing users to practice web scraping, crawling, and data extraction.

## How it works

ScrapingSandbox offers a collection of 500 products across 15 categories and 20 vendors. Users can search, filter, paginate, and inspect real-world product data to practice web scraping and data extraction using tools like Playwright, Puppeteer, or Agenty AI.
