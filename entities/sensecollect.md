# SenseCollect

## What it is

SenseCollect is a self-service platform designed to simplify web data extraction for lead generation and market intelligence. It provides simple scraping tools that allow users to extract structured web data quickly, focusing on providing clean CSV outputs for spreadsheet workflows.

## How it works

The process for extracting data involves three simple steps. First, the user chooses a tool, such as Google Maps leads or Instagram followers export. Second, the user enters a query, location, and run size in plain language. Finally, the user downloads the resulting structured CSV file when the job is complete.
