# FingerprinterJS

## What it is

FingerprinterJS v2.0 is a browser fingerprinting and bot detection tool. This major release includes a complete architecture overhaul, 19 collectors, and advanced bot detection capabilities.

## How it works

FingerprinterJS v2.0 works by collecting various data points from the user's browser environment, such as system information, browser settings, and network configurations. These data points are then used to create a unique fingerprint that can be used to identify and potentially block bots. The tool also includes advanced bot detection features to enhance its effectiveness.
