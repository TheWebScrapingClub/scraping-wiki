# Crawl4AI

## What it is

Crawl4AI is an open-source web crawler and scraper designed to generate LLM-friendly Markdown output. It is built to be fast, controllable, and battle-tested by a large community of users.

## How it works

Crawl4AI operates by using an asynchronous browser pool, caching, and minimal hops to ensure fast and efficient web crawling. It also supports full control over sessions, proxies, cookies, and user scripts, allowing for adaptive intelligence that learns site patterns and explores only what is necessary. The tool is deployable anywhere, requiring no API keys and supporting both CLI and Docker deployments.
