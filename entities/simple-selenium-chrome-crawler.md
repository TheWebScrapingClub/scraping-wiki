## What it is

A Python script that uses Selenium and Chrome to crawl web pages and extract links.

## How it works

The script first installs Selenium and Chromedriver, then loads a page, waits for 5 seconds, and closes the browser. It then reads a list of URLs from a file, visits each URL, extracts all the links, and saves them to another file.
