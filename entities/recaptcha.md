## What it is

reCAPTCHA is Google's CAPTCHA system, originally acquired from Carnegie Mellon University in 2009. It dominates the CAPTCHA market with approximately 98% share as of 2022. It has evolved through three major versions, moving from explicit puzzle-solving toward invisible behavioral scoring.

## How it works

### v1 (2007-2018)
The original version showed distorted text from scanned books. One word was a known control, the other was sourced from OCR uncertainty. User responses were aggregated to help Google digitize books. As ML improved, bots achieved 99.8% solve accuracy on text CAPTCHAs, rendering v1 obsolete.

### v2 (2014)
Introduced the "I'm not a robot" checkbox. Google JavaScript monitors page behavior before the checkbox is clicked: mouse movement, click speed, browser environment, and especially Google account cookies. Trusted sessions pass with just the checkbox. Suspicious sessions receive an image-selection challenge (typically from Street View imagery). The checkbox triggers a server-side token validation via Google's API.

### v3 (2018)
Fully invisible. No checkbox, no puzzles in normal operation. The `grecaptcha.execute()` call runs silently, collects telemetry, and returns a token representing a risk score from 0.0 (likely bot) to 1.0 (likely human). Site operators set a threshold and decide the action: allow, challenge further, or block. Google recommends embedding v3 on all pages, which means continuous user tracking across the protected site. This raised privacy concerns when v3 launched.

reCAPTCHA Enterprise extends v3 with custom tuning and the ability to fall back to v2 challenges for low-confidence cases.

### How Google scores sessions
v2 and v3 scoring is influenced by: Google account cookies (logged-in users get higher scores), browser environment fingerprint (canvas, hardware), behavioral signals, and IP reputation. A Tor exit node or datacenter IP will score low regardless of browser behavior.

## Bypass approaches tested

### Open-source token extraction (anchor URL exploitation)
Tools like EvickaStudio's BypassV3 and PyPasser replicate the HTTP requests that the real reCAPTCHA script makes, using the anchor URL to obtain a `g-recaptcha-response` token without a browser. The anchor URL contains the site key and domain and is visible in the browser's network tab.

**Problem**: Tokens obtained this way produce low scores because they are generated without a real browser fingerprint. Using such a token in the actual payload reliably results in "Unusual activity detected" errors. Additionally, tokens are single-use, so there is no way to verify the score of a token before deploying it.

**What also failed**: Using rnet or hrequests (TLS-fingerprint-aware HTTP clients) as the session for token generation did not improve scores. The payload of the `reload` endpoint generated by the library differed entirely from what a real browser sends, indicating deeper protocol-level detection beyond TLS fingerprinting. Covered in [bypassing-recaptcha-v3](https://substack.thewebscraping.club/p/bypassing-recaptcha-v3).

### Camoufox (successful)
Browsing the target site with Camoufox and interacting normally with the reCAPTCHA-protected form bypassed v3 without any special handling. Camoufox's Firefox-based fingerprint was sufficient to generate a passing token transparently. Covered in [bypassing-recaptcha-v3](https://substack.thewebscraping.club/p/bypassing-recaptcha-v3).

### Commercial solvers
Services like NextCaptcha, 2captcha, and anti-captcha farm reCAPTCHA challenges to human workers or use specialized infrastructure. NextCaptcha's SDK submits a task, polls for the result, and returns a `gRecaptchaResponse` token. In testing on completedns.com, NextCaptcha returned a token but the subsequent POST request still returned an error response, suggesting the token score was insufficient or fingerprint consistency between the solver and the request was not maintained. Covered in [bypassing-recaptchas-with-open-source](https://substack.thewebscraping.club/p/bypassing-recaptchas-with-open-source).

## Alternatives and competitors

- **hCaptcha**: Main competitor. Similar image-challenge UX. Cloudflare switched from reCAPTCHA to hCaptcha in 2020 over privacy concerns and cost. More privacy-focused, does not factor in Google account cookies.
- **Cloudflare Turnstile**: Fully invisible. Uses lightweight rotating background challenges. Integrates with Private Access Tokens (Apple attestation standard). No cookies required.
- **Friendly Captcha**: Proof-of-work approach. Browser completes a computational puzzle; no user interaction required. Privacy-preserving.
- **Geetest**: Slider puzzle interaction. Originally popular in Asia. Offers invisible mode.

## Current state

As of 2025 research, AI models outperform humans on CAPTCHA solving tasks by up to 15%. The trend across the industry is toward invisible or device-attested challenges that eliminate the puzzle entirely. reCAPTCHA v3's risk score model represents this direction, though its reliance on Google tracking and cookies remains a privacy concern and a practical dependency for scrapers who lack Google account signals.

Camoufox is the most reliable open-source approach for sites using reCAPTCHA v3, as of June 2025 testing on completedns.com.
