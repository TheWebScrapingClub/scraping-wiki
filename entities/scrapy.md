# Scrapy

## What it is

Scrapy is a Python library that is used in typical web scraping setups.

## How it works

Scrapy is one of the web scrapers included in a typical setup for AI data collection. It is used alongside other components such as proxy server rotation services, job schedulers for managing concurrent requests, and cloud storage for collected data.
