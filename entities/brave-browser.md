# Brave Browser

## What it is

Brave is an 11-year-old, privacy-focused browser company.

## How it works

Brave built an index of more than 30 billion web pages using an unidentified crawler, which left publishers unable to block it. The browser also features a capability that bypasses paywalls and allows the company to block publishers’ ads while selling its own.
