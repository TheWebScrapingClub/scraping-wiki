# shomei

## What it is

Shomei is a Rust-based authentication proxy designed for both HTTP and TCP traffic. It leverages hardware-attested YubiKeys to secure access, offering features like browser WebAuthn and one-use CLI assertions for HTTP, and short-lived mTLS certificates for TCP connections. It also supports tunneling OpenSSH through a YubiKey-approved certificate and can integrate with Tailscale SSH to require YubiKey approval before establishing a direct connection.

## How it works

Shomei acts as a gateway, verifying user authentication through hardware-backed YubiKeys. For HTTP traffic, it supports WebAuthn for browser-based authentication and one-use CLI assertions. Subsequent HTTP requests can be authenticated using encrypted session cookies. For TCP traffic, Shomei issues short-lived mTLS certificates to authorize connections. It can also be configured to tunnel OpenSSH connections, requiring YubiKey approval to establish a secure channel to a specified upstream.

The system requires a supported YubiKey 5 Series key with specific firmware, a PIN, and touch input for authentication. All enrolled keys are treated under the `shomei` account. Shomei decodes and verifies hardware attestations of compressed records in memory. Configuration involves setting up a public HTTPS origin, TLS certificates, and defining upstream destinations for HTTP or TCP traffic. Identity management is handled through an identity file containing tokens generated by `shomei get-id`.

## Known limitations
