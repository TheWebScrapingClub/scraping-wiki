# Libretto

## What it is

Libretto is a toolkit for building robust web integrations. It provides a live browser and a token-efficient CLI to inspect live pages, capture network traffic, record user actions, and replay them as automation scripts. Libretto is designed to help maintain browser integrations to common healthcare software and is open-sourced by Saffron Health.

## How it works

Libretto allows users to interact with a live browser through a CLI. It can inspect live pages, capture network traffic, record user actions, and convert browser automations into network requests. The toolkit is designed to be used as a skill through a coding agent, enabling one-shot script generation, interactive script building, and fixing broken integrations. It also supports direct network script generation and security analysis.
