# PageSieve

## What it is

PageSieve is a browser extension designed for declarative web scraping. It enables users to define field names and use CSS or XPath selectors to extract structured data from any website they visit.

## How it works

The extension operates entirely within the user's browser, performing all scraping locally. Users define extraction rules using selectors, allowing them to target specific elements on a webpage.

Scrape configurations can be saved and shared as JSON files, allowing for the creation of reusable scraping recipes.
