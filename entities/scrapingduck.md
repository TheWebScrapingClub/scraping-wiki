# ScrapingDuck

## What it is

ScrapingDuck is a scraping API that handles IP rotation, JavaScript rendering, and provides a free tier for web scraping. It is designed to help users reliably extract data from websites by managing common issues such as IP bans and complex JavaScript.

## How it works

ScrapingDuck works by rotating IP addresses to avoid getting blocked, rendering JavaScript to handle dynamic content, and providing a free tier for users to start scraping with a generous daily limit. The API key is used to authenticate requests, and the service can be accessed via an endpoint that returns raw HTML.
