# Slick Search Engine

## What it is

Slick is a customizable search engine designed to give users control over their search results. It allows users to block unwanted sites, prioritize trusted sources, and switch indexes to gain more coverage, with all preferences stored locally on the user's device.

## How it works

Slick operates on its own crawl and ranking stack, which is then layered with personal rules defined by the user. Users can pin domains, block sites, set recipes to reshape search recall, and create different profiles (such as Shopping, Research, or Work), each carrying its own set of ranking rules and blocked domains.
