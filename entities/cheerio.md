# Cheerio

## What it is

Cheerio is a library used in the Node.js environment for parsing HTML and extracting data from web pages.

## How it works

The library is used to load HTML content into a structure that allows for jQuery-like syntax. Once loaded, selectors are used to target specific elements on the page.
