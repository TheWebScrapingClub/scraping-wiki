# Residential Proxy Observatory

## What it is

The Residential Proxy Observatory is a first-of-its-kind interface designed to provide researchers with a global view of residential proxy activity and anonymized internet activity.

## How it works

The observatory functions as an enumeration pipeline that tracks residential proxy exit activity across various networks. It collects data on where residential proxies are exiting traffic, allowing researchers to observe patterns in proxy usage and anonymization infrastructure worldwide.
