# Kampala

## What it is

Kampala by Zatanna is a tool for intercepting and automating web traffic. It allows you to reverse engineer any web flow, including websites, mobile apps, and desktop apps, by seeing every HTTP/S request in real time. Kampala helps in mapping tokens, cookies, sessions, and multi-step sequences automatically, and it can capture and replay sequences as stable automations while preserving your HTTP/TLS fingerprint.

## How it works

Kampala intercepts all HTTP/S requests from any app or browser in real time. It then maps out authentication chains and sequences of interactions, allowing you to trace and automate these flows. The tool maintains the original HTTP/TLS fingerprint to ensure that intercepted traffic behaves identically to the original, making it a powerful tool for web scraping and automation.
