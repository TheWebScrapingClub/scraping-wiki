# MeshScrape

## What it is

MeshScrape is a service that offers a distributed IP network for web scraping to avoid blocks and rate limits. It helps companies collect public web data reliably through a peer-to-peer network of millions of real user devices.

## How it works

MeshScrape dynamically routes your request through its global network of real residential nodes. You send your target URL via their simple REST API or SDK, and they handle the routing and ensure you receive clean, unblocked HTML or JSON responses.
