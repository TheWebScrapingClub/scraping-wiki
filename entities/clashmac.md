# ClashMac

ClashMac is a native macOS proxy tool with real-time traffic monitoring, topology visualization, and multi-hop transit capabilities. It provides a native SwiftUI architecture, offering dual-mode proxy functionality. The tool includes features such as real-time traffic monitoring, subscription status, proxy group switching, and quick actions accessible from the menu bar. It also supports multi-hop transit visualization, live flight tracking, and a detailed topology view of network traffic.

## How it works

ClashMac operates as a native macOS application with a focus on real-time traffic monitoring and network topology visualization. It allows users to manage proxy groups, switch between nodes, and configure rules directly from the menu bar. The tool supports various proxy modes, including HTTP/SOCKS5 system proxy and TUN enhanced mode for global traffic capture. ClashMac also includes features like smart configuration, smart rule management, and one-click rule creation for the current browser page.
