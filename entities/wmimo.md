# Wmimo

## What it is

Wmimo is a modern, cross-platform GUI client developed using Flutter, designed for managing Clash and Mihomo proxy configurations on both desktop and mobile platforms. It is engineered to provide a fast, elegant, and flexible interface for handling various proxy protocols.

## How it works

The client is built with Flutter and utilizes the high-performance Mihomo core to handle proxy operations. It supports a full suite of protocols including Shadowsocks, VMess, VLESS (Reality), Trojan, Hysteria 1/2, TUIC v5, WireGuard, SSH, and Direct.

Wmimo features intelligent routing capabilities, allowing users to toggle between Rule (Split Routing), Global, and Direct modes. It operates using a dual-engine approach, offering both TUN Virtual Adapter Mode for system-wide traffic capture and System Proxy Mode for standard unprivileged routing.
