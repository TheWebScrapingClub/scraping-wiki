# Stalker

## What it is

Stalker is a tool designed to check and report various browser and network fingerprints for privacy and analysis.

## How it works

The tool collects and reports various signals across network, browser, display, fingerprint, and privacy categories. This data includes public IP address, operating system details, browser version, CPU cores reported, screen resolution, GPU vendor, and various privacy settings.
