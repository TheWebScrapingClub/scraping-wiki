# xcancel.com/antibot/captcha

## What it is

This page presents a CAPTCHA challenge requiring users to "Type the coloured characters." It includes an image for verification and provides options for retrying the challenge or obtaining a new image if the initial attempt does not match.

## How it works

The interface displays a CAPTCHA image and prompts the user to input the characters. If the input does not match the image, the system prompts the user to try again or verify by getting a new image.
