# Spidra

## What it is

Spidra is a web scraping platform that uses AI to extract data from websites. It offers a user-friendly interface where users can describe what they want to extract in plain English, and the platform handles the scraping process, including CAPTCHA solving, proxies, rate limits, and anti-bot systems.

## How it works

Spidra offers a playground and an API that is reliable, fast, and scalable. Users can target any URL and describe what they want to extract in plain English. The platform then handles the scraping process, including crawling, discovering pages, analyzing links, scoring and filtering, and extracting data. The output is clean, structured data ready to use immediately, which can be exported to JSON, CSV, or delivered to various destinations like Slack, Discord, webhooks, or databases.
